# تحلیل سفرهای NYC TLC

این پروژه داده‌های سفر نیویورک را با تمرکز بر **High Volume FHV** بررسی می‌کند. هدف اصلی، پیش‌بینی زمان انتظار مسافر از ثبت درخواست تا سوارشدن است.

## وضعیت پروژه

فاز 1 شامل شناخت داده، ممیزی ساختار و کیفیت، تحلیل اکتشافی و انتخاب سؤال پژوهش است. آموزش و ارزیابی مدل در مراحل بعد انجام می‌شود. همهٔ فازها در همین ریپازیتوری نگهداری می‌شوند؛ برای دسترسی به نسخهٔ فاز 1، tag مربوط به آن را از بخش **Tags** گیت‌هاب انتخاب کنید.

## مشاهدهٔ نتایج

فایل `phase1.pdf` را باز کنید.

## اجرای تحلیل

ورودی‌های لازم:

- `hvfhv_2024_random_sample.csv` و `hvfhv_2025_random_sample.csv`: نمونه‌های سفر.
- `taxi_zone_lookup (1).csv`: جدول تبدیل شناسهٔ ناحیه به مشخصات مکانی.
- `data_reports_monthly.csv`: نسخهٔ آمار ماهانهٔ TLC استفاده‌شده در گزارش.

از پوشهٔ حاوی کد و این فایل‌ها اجرا کنید:

```bash
python -m pip install "pandas>=2" numpy matplotlib tzdata
python phase1_plots_v1.20.29.py hvfhv_2024_random_sample.csv hvfhv_2025_random_sample.csv --zone-lookup "taxi_zone_lookup (1).csv" --tlc-monthly data_reports_monthly.csv
```
.
## نکات استفاده از داده

تحلیل‌های اکتشافی با `_sample_weight` انجام می‌شوند تا سهم سفرهای هر ماه حفظ شود. مقدار خالی فقط از تحلیلی کنار گذاشته می‌شود که به همان متغیر نیاز دارد؛ انتظار منفی نیز از تحلیل انتظار حذف می‌شود. فایل‌های ورودی تغییر نمی‌کنند.

نتایج دربارهٔ سفرهای ثبت‌شده‌اند و همهٔ درخواست‌های لغوشده یا انجام‌نشده را پوشش نمی‌دهند.

منبع داده: [NYC TLC Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)
